Create and test haptics right from the smartphone

I work in product design and I love diving deep into craft solutions. I can spend hours coming up with yet another version of how a particular interaction might look. I believe that every part of the user experience is the designer’s responsibility. But one part has always been hard for me to access — tactility. It’s difficult for designers to work with haptics because it’s unclear how they’re designed, what properties they have, and how they’re applied in app development. So I decided to create a tool that removes this barrier between the designer and tactile feedback and makes it visually understandable — so that a designer can cover this part of the user experience, too.

Creating files

On the app's home screen, users can create a file and also test how their previously created haptic files work, to better understand which one they want to open.

Create haptic event

When I was developing the app, I tried to use interaction patterns that designers are already familiar with, so when creating a haptic file, the designer sees a timeline. They can add haptic events, which come in two types: vibration and impulse. After that, in edit mode, the user can adjust the intensity, duration, and frequency of the event using contextual sliders. This allows you to quickly set up the basic haptic event settings, which are sufficient for basic haptics.

Advanced properties

Here, the user can perform more specific actions with the haptic event, add a fade effect, and adjust the settings more precisely

Sharing

After creating a haptic, the user can share several file versions with developers or use a code snippet. There's no need to save the file — it's stored in the cloud.
